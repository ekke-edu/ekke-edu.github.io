Újdonság · nyílt forráskód

Kérdezz az EKKE tudásbázisától.

Az ekke-mcp egy MCP-szerver, amely kurzusanyagokban, GitHub Discussionökben és az egyetem nyilvános oldalain keres. Magyarul és angolul is kérdezhetsz; a válaszok forráslinkeket adnak.

MCP
01Kurzusrepo-k, publikus issue-k és szervezeti Discussionök keresése.
02Hivatalos EKKE-oldalak keresése tanulmányi információkhoz.
03Magyar és angol keresőkifejezések automatikus bővítése.
04Csak nyilvános forrásokat olvas; nem fér hozzá Neptunhoz vagy hallgatói adatokhoz.
mcp.json
{
  "mcpServers": {
    "ekke-university-assistant": {
      "command": "npx",
      "args": ["-y", "ekke-mcp"],
      "env": {
        "GITHUB_TOKEN": "YOUR_READ_ONLY_TOKEN"
      }
    }
  }
}

A GitHub-token a Discussionök kereséséhez kell. Token nélkül is működik a keresés a kurzusanyagokban és a hivatalos oldalakon.
